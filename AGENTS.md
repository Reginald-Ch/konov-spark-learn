# Project rules
- Keep company-page sections in a shared presentation module so the homepage and About express the same company–product relationship without duplicated layouts.
- Keep homepage FAQ content and its structured data sourced from the same exported dataset so visible answers and search metadata remain consistent.
- Use the shared navigation with a focus-trapped, scrollable mobile dialog and a grouped Explore menu so all destinations remain accessible on short screens.
- Keep static route metadata aligned with page SEO props, including route-specific keywords, and mark template head tags as Helmet-managed so navigation replaces them rather than duplicating them.
- Preserve the company identity in organization structured data across routes; route descriptions belong to page metadata, not the organization.
